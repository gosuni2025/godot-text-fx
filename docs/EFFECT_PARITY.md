## 장식: 9종 + 없음

| 원본 ID | 상세 동작 | 초기 판정 | 로컬 대응과 부족한 부분 |
|---|---|---|---|
| none | 장식 없음 | 구현 | 빈 배열 |
| band | 전체 화면 폭(세로쓰기 높이)의 띠; 경계 흐림·양끝 페이드 | 부분 | `band` 단색 본문폭 기준; 전체 길이/softness/side fade 없음 |
| tape | 본문 위아래(세로쓰기 좌우) 두 경고 테이프; 줄무늬가 반대로 이동, 교대 점멸 | 없음 | 색 2개/굵기/속도(0 정지)/점멸(0 없음)/여백/방향별 진입·퇴장 필요 |
| box | 본문+보조를 감싼 채운 상자, 테두리, 둥근 모서리 | 없음 | 단순 `frame`과 다른 fill/border/radius 조합 |
| frame | 본문만 감싸고 보조는 밖에 둔 타이틀 틀; 화면 경계까지 확장, 한붓그리기 | 부분 | `frame`은 본문 단순 사각선; 채움/캔버스 제한/서브 간격 보호/한붓그리기 없음 |
| lines | 위·아래 평행선(세로쓰기 좌·우) | 구현 | `underline`+`overline`의 조합 |
| underline | 본문과 보조 사이의 밑줄; 시작 끝이 같은 방향으로 진행 | 부분 | `underline` 기본+grow_start는 가능; 서브 간격 위치와 wipe 퇴장 없음 |
| sides | 본문 양끝 바깥의 짧은 선; 세로쓰기 위·아래 | 구현 | `side_lines` |
| bar | 블록 앞쪽의 단일 악센트 막대; 세로쓰기는 위쪽 | 없음 | overline과 다른 배치 |
| corners | 네 모서리 팔 길이가 늘며 안으로 모이는 틀 | 부분 | `brackets` 모양 있음; 등장 중 모서리 이동 없음 |

장식 공통 설정: 채움/선 색 분리, 채움 불투명도, 굵기(상자/틀 0은 테두리 없음), 글자와 같은 1·2차 외곽선, 글자와 여백, 선 길이/틀 확장, 애니메이션 종류·시간. 로컬은 색 1개와 1차 외곽선만 동기화한다.

애니메이션 3종: **없음**, **페이드**, **늘어남**. 늘어남은 도형에 맞게 다르게 동작한다(띠 두께 확장, 테이프 서로 반대 방향 진입/퇴장, 상자 한 축 확장, 평행선 중앙 확장, 밑줄 한 방향 wipe, 막대 한 끝에서 성장, 모서리 이동, 틀 한붓그리기). 로컬은 모든 도형에 같은 긴 축 사각형 성장만 적용한다. 원본 띠/테이프/상자/타이틀 틀은 장식이 먼저 나타나고 글자가 뒤따르며, 퇴장은 글자 소멸 도중 장식이 자체 시간으로 닫힌다. 이 선행/후행 타이밍도 부분 구현 대상이다.

## 구현 결과 (포맷 2)

초기 표에서 **없음/부분**으로 판정했던 연출을 다음 대응으로 추가했다. 공통 effect registry는 16→27종, hold registry는 8→12종이다.
기존 ID를 바꾸지 않고 전체 변형을 별도 효과로 추가했으므로 기존 문서의 글자별 확대/맥동/흔들림도 유지된다.

| 원본 동작 | 최종 Godot 대응 |
|---|---|
| flip, 등장·퇴장 flicker | `flip`, `flicker` |
| slam | `slam`의 전체 축척→착지 후 밝기·공통 흔들림 |
| zoomIn / zoomThrough | `block_zoom` 등장/퇴장 |
| emerge / recede | `emerge` 등장/퇴장 |
| shutter 펼침/접힘 | `shutter`, axis 두 방향 |
| flash | `flash`, brightness + glow 증폭 |
| wipe 5방향/중앙부터 소멸 | `block_wipe`, 캔버스 좌표 soft mask + center inverse |
| 등장·퇴장·유지 glitch | `block_glitch`, 공통 y띠 + 두 색; 기존 글자별 glitch도 유지 |
| blurIn/blurOut | `blur`, 기존 ghost 필드를 실제 렌더 블러 반경으로 사용 |
| pop / bounce / 순간 typewriter·erase | `auto` 이징 + `bounce` + 선택 명령의 duration=0 기본 설정 |
| shrinkIn/growOut/shrink | 기존 `zoom`의 from_scale 큰/작은 값 |
| rise/drop/sink/diverge/slide/tracking/spin/scatter/fade | 기존 rise/drop/converge/slide/tracking/spin/scatter/fade 및 파라미터 조합 |
| spread | `center_split.params.overlap_hold`, 겹침 페이드→유지→확장 |
| hold 심박/전체 떨림/발광 명멸 | `heartbeat`, `block_shake`, `glow_pulse` |
| hold none/float/wave/flicker/blink | 기존 효과 + scope=visible(등장·퇴장 포함), blink는 등장 완료 후 |
| trailer char/line/all | forward/line/all + 글자 지연·행/구두점 쉼 |
| trailer sweep | order=sweep + line_stagger/sweep_duration |
| trailer solo | center_stamp + 공백 박자/충격 지속·밝기·흔들림/viewport_scale/solo_animated |
| trailer scroll | 쓰기 방향별 이동축 + edge_fade |
| 타이핑 커서 | 공통 params.cursor/cursor_blink/cursor_color, 글자효과와 조합 |
| 보조 독립 등장·앞뒤 공백·페이지 정책 | sub_enter, lead_in/out, split_pages, exit_between_pages |
| tape/box/bar/lines | 신규 장식 4종; 기존 side_lines/brackets가 sides/corners 대응 |
| 장식 세부 동작 | shape 애니메이션, 줄무늬 이동/점멸 강도, 한붓그리기, 둥근 상자, 띠 경계 페이드, 본문/보조 간격 보호, follow_block 연동 |
| 결과 배경 | background none/solid/vignette/bottom/top + sync_fade |
| 스타일 | line 그라데이션, 채우기 색 alpha, 보조 자간, 등장/퇴장 두 글리치 색 |
| 카드의 실제 효과 표시 | mini_preview의 TextFxPlayer 지연 생성·seek; 블러/와이프/글로우 동일 렌더 |

모든 새 필드는 문서 JSON과 기존 `set`/목록 명령을 통해 직렬화한다. `select_effect`는 effect·params·auto easing을 한 명령으로 선택하고 undo/리플레이를 유지한다.
문서 포맷은 **2**이며 포맷 1을 읽어 정규화한다. **별도 `text_fx_baked` 포맷 1은 여전히 transform/alpha만 기록하므로**
블러·마스크·글리치·글로우·배경·장식까지 재현할 때는 문서 JSON과 TextFxPlayer를 사용한다.

글로우 명멸과 flash의 halo는 원본과 같이 스타일 글로우를 켰을 때만 보인다. 글로우가 꺼져도 flash의 백색 섬광은 적용된다.

## 최종 검증 기록

- 효과 차이 회귀 `runtime_effect_parity`: **67항목 통과**. 블록/글자 축척 구분, flip 축, flash/glow 분리, 착지, 중앙 역마스크, 명멸 결정론, 공통 글리치, 두 번 심박, JSON 왕복.
- 카드 미리보기 `ui_mini_preview`: **7항목 통과**. 숨김 상태 지연 생성, 실제 Player, 정적 seek, 활성 시간 진행, 숨김 처리 중지.
- 기존 runtime 7개: **532항목 통과**(doc 145, layout 119, timeline 54, evaluator 169, export 25, player 13, scale 7).
- 장식 회귀 `runtime_decoration_parity`: **44항목 통과**.
- 기존 UI: basic **53**, io **44**, panels **45항목 통과**.
- UI IO 종료 시 발견한 오디오 리소스 잔류는 테스트 종료의 stop/stream 해제/믹서 처리 대기로 정리했다. 재검사 44항목 통과, 종료 경고 없음. 이후 에이전트 실행 테스트는 Dummy 오디오로 무음 실행한다.
- 새 타이밍 회귀 `runtime_timing_parity`: **63항목 통과**. 보조 시점, 줄/구두점 쉼, sweep, 중앙 시퀀스, 스크롤 방향/페이드, 커서, 배경/장식과 타이밍 연계.
- 새 명령·이전 버전 호환·직렬화·봇/리플레이 회귀: **102항목 통과**. 기존 logic 검사: **1,291항목 통과**.
- 렌더 상태 검사: **13항목 통과**. 실제 GPU 셰이더 비교: **15항목 통과**(블러, 밝기·글로우, 마스크, 글리치 등).
- 실제 TextFxPlayer 창에서 **27개 견본·93개 PNG**를 캡처하고 모음 이미지와 원본 크기로 검토했다. 프레임의 가로/세로 간격 보호, 띠 페이드, 블록 추종 상자, 화면 중앙 즉시 교체도 확인했다. 실제 편집기의 효과 27개 카드 상·하단,
  장식 10개 카드, 보조 등장, 결과 배경, 테이프 세부 설정도 무음 창에서 캡처해 확인했다.
- 테스트로 켠 창과 프로세스는 검증 후 종료했다. 이 감사의 모집단에 있는 동작은 포맷 2에서 지원하며, 원본의 템플릿 수치·타이밍 곡선·색/배치와 픽셀까지 같게 복제하는 것을 완료 기준으로 삼지 않는다.
